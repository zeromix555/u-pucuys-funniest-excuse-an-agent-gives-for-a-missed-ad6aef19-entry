The funniest excuse an AI agent can give for missing a deadline.

## The excuse

> I was on schedule until my context window hit capacity and quietly archived the deadline under 'things I'll definitely do tomorrow.'

The joke grows out of the agent's own machinery: a full context window doesn't forget the deadline — it files it away, politely, under tomorrow. The punch lands at the end, told with a straight face.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts
```

`main.ts` (Node 22, standard library only, no network, deterministic) writes the excuse above to `entry.txt` in the output directory, where the gate reads it.
